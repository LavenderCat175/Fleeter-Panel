What is Fleeter?

Fleeter came about because of a need to remotely control a group of class computers. We were unhappy with the existing apps and decided to replicate the DFG systems, in a more professional way than what we are used to. Enforcers (admins) can connect to Fleet devices and block their screens.

Fleeter Components

Server

Fleeter Server is the core of Fleeter. It is where both the Enforcers and the Fleet connect and manages information exchange between the two. It is made up of custom and off the shelf solutions.

Fleeter app is an asynchronous socket.io server that handles inbound and outbound traffic.

Keycloak is an authentication server that verifies credentials of enforcers.

Postgres stores the Keycloak data.

nginx proxies all this traffic into one port to permit easier management and connection attempts. This is all managed by a compose instance (podman and docker compatible).

The off the shelf solutions were intentionally chosen as this is how many corporations operate. Programming everything from scratch is useful for learning, but a product's only value is how it functions. Specialised software is often more secure and well maintained.

Manager

Managers manage the Fleet by running on the devices. It is a simple asynchronous socket.io client that connects via the /fleet namespace. The client is authenticated with a JWT token encrypted and issued by the server; it contains key connection info.

To block the devices, a tkinter (chosen for compatibility) window is used as a visual block and pynput halts mouse and keyboard input. Managers send a heartbeat to the server every second, notifying it of their status.

Panel

The panel is a python based web app running on pyscript, a cutting edge WASM based javascript alternative. It however does rely on the socket.io javascript client. It is portable and can be used locally or remotely.

To authenticate with the Fleeter Server, it connects to the exposed keycloak instance and uses user credentials to issue a token, which it then passes to the socket.io connection request. It communicates to the server on the /enforcer namespace.
